socio4health.Survey#

class socio4health.Survey(name: str, country: str, years: ~typing.List[int], parts: ~typing.List[dict], reader: dict, column_mapping: str, value_mapping: str, household_key: ~typing.List[~typing.List[str]], person_key: ~typing.List[~typing.List[str]], group_col: str = 'ADMIN_DIVISION', factor: dict | None = None, person_factor: dict | None = None, file_groups: ~typing.List[dict] = <factory>, unify_columns: ~typing.List[str] = <factory>, periods_per_year: int = 1, vertical_merge: bool = True, keep_rows: ~typing.Dict[str, list] = <factory>, keep_rows_any: ~typing.List[dict] = <factory>, fill_missing: ~typing.Dict[str, dict] = <factory>, derive_from_flags: ~typing.Dict[str, dict] = <factory>, derive_from_rules: ~typing.Dict[str, list] = <factory>, map_columns: ~typing.List[dict] = <factory>, row_ids_without_key: bool = False, relative_weight_years: ~typing.Dict[str, ~typing.List[int]] = <factory>, notes: dict = <factory>, data_root: ~pathlib.Path = PosixPath('.'), mappings_dir: ~pathlib.Path = PosixPath('.'))[source]#

One survey. Every rule is optional except the files, mappings and keys.

name, country

Survey and country codes (e.g. "GEIH", "COL").

Type:

str

years#

Years to process.

Type:

list of int

parts#

Folders of each year, relative to data_root ({"path": "PNAD/dom/{year}"}). Fixed-width files add "ibge_dictionary" (glob of the IBGE dictionary of the year) and "shared_dictionary" (glob of a dictionary covering several years, named ..._2012_a_2014_...).

Type:

list of dict

reader#

Extractor arguments (down_ext, sep…).

Type:

dict

column_mapping#

JSON {"<year>" or "<first>-<last>": {raw column: harmonized name}}.

Type:

str

value_mapping#

JSON {raw column: {raw code: harmonized code}}, optionally inside "mapping"; {year} in the name gives one file per year.

Type:

str

household_key, person_key

Alternative raw keys, the first one a table has is used. HOUSEHOLD_ID joins the household key with -; PERSON_ID adds the person key (or the order within the household).

Type:

list of list of str

group_col#

Unit column used for the shares (ADMIN_DIVISION or ADMIN_DIVISION_2).

Type:

str

factor, person_factor

Weights: {"factor_col", "id_col", "fallback_col"}. person_factor weights person tables with a population factor (see use_person_factor()).

Type:

dict, optional

file_groups#

Read the files in groups: {"pattern": regex on the file name, "assign": {column: value}}.

Type:

list of dict

unify_columns#

Columns spelled differently in some files (BOM, case): the variant replaces the exact name.

Type:

list of str

periods_per_year#

Samples per year expanded to the whole population (12 for monthly samples): weights are divided by it.

Type:

int

vertical_merge#

Stack the tables with nearly the same columns before harmonizing.

Type:

bool

keep_rows#

{column: [codes]}: only rows with these codes.

Type:

dict

keep_rows_any#

Rows meeting every condition of at least one rule; applied to tables that have every column.

Type:

list of dict

fill_missing#

{column: {"from": column, "values": [codes]}}: empty values take these codes of another column.

Type:

dict

derive_from_flags#

{column: {flag column: code}}: code of the only yes/no flag that is yes (s4h_code_from_flags()).

Type:

dict

derive_from_rules#

{column: [{"when": {column: [codes]}, "code": code}, ...]}: code of the first rule whose conditions a record meets, for variables built from several columns, e.g. completed education from level, grade and title (s4h_code_from_rules()).

Type:

dict

map_columns#

{"years", "source", "target", "mapping"}: fill target from source with a JSON mapping when a table has the source but not the target (e.g. regions from provinces).

Type:

list of dict

row_ids_without_key#

Tables without any key get row IDs; their persons are not linked to households.

Type:

bool

relative_weight_years#

{"households": [years], "persons": [years]} whose weights are normalized (average 1).

Type:

dict

notes#

Free explanations of the rules; not used by the pipeline.

Type:

dict
